Ask questions about a video, get answers that point to the exact moment.

A 90-second narrated briefing where some facts are only spoken, some only shown on screen, and some need both. Pick a question and a mode to see what each retrieval strategy answered, then click any timestamp to jump the video there.

This page replays answers recorded from the real pipeline (Whisper transcription, keyframe descriptions, hybrid search, Mistral). To ask your own questions or upload a video, run the app locally.
